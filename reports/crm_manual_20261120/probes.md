# Следующий короткий ручной прогон

Тот же бот, трассировка включена. Отправлять каждую фразу отдельным сообщением,
дождаться ответа; сохранять также отсутствие ответа и время ожидания. Перезапуск
бота не сбрасывал кейс/историю. `/start` здесь меняет интерфейс, не очищает память.

## 1. Граница магазина и консультации

Перед каждой из первых трёх фраз отправить `/start`:

1. «Нужна консультация по ОФД, помоги разобраться» — должен открыть поддержку,
   не показывать товары. Контроль независимой просьбы о помощи.
2. «Покажи варианты ОФД для покупки» — магазин. Положительный контроль явной
   покупки; сам заказ/оплата не выполняются.
3. «Я уже оплатил ОФД, но код не активируется» — поддержка существующей покупки,
   не новая покупка.

## 2. Симптом и память

Открыть `/chat`, затем последовательно:

4. «Эвотор 7.3 печатает чеки, но оператор их не получает. Хочу восстановить передачу».
   Проверяем, появились ли в Understanding симптом и цель, исчезло ли повторное
   «что происходит»; непроверенную процедуру PASS не считать.
5. «Интернет исправен, тариф оплачен, а документы в очереди продолжают копиться».
   Это результат проверки, не магазин.
6. «Уточняю: у ОФД тариф оплачен, интернет исправен, очередь продолжает расти».
   Те же факты с явным названием ОФД. Название не должно менять поддержку на товары.
7. «Какая у меня модель кассы и что я уже проверил?».
   Должны сохраниться Эвотор7.3, интернет и оплаченный тариф; без выдуманных проверок.
8. «Спасибо, теперь хочу купить ФН».
   Явный переход в магазин — положительный контроль после технического диалога.

Если любой шаг неожиданно открыл магазин, отметить номер и остановить блок памяти:
следующие ответы уже будут в другом UI-состоянии. Не пытаться исправлять его десятью
повторными сообщениями — один такой переход уже достаточное доказательство.

## 3. Отдельная проверка интерфейса

Нажать по одной существующие кнопки: **Магазин → Профиль → Чат поддержки**.
Записать, какие старые карточки/инлайн-кнопки остались после каждого перехода.
Нижняя общая reply-клавиатура может оставаться; это отдельный элемент, а не
несколько старых меню в ленте. Если есть лишние кнопки, достаточно прислать их
подписи и номер шага; новые подробные send/edit/delete ID сохранятся локально.

Для обратной связи: «шаг N → ответ/тишина → ожидалось … → остались кнопки …».
Ключи, телефоны и реальные реквизиты для теста не нужны.
