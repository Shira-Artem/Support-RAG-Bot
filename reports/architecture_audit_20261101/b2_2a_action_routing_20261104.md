# B2.2a — маршрутизация процедурной цели, 04.11.2026

**Итог: NO-GO для quality gate.** Две процедурные формулировки достигли подходящей статьи и получили её точный частичный факт, но полный порядок действий не дан; отрицательный контроль дал ошибочное неподтверждённое определение. Кодовая правка остаётся локальным кандидатом, она не закрывает качество ответа и не разрешает production. [Сценарии до запуска](b2_2a_cases_20261104.md), [полный live trace](b2_2a_live_20261104.json), [B2.1 baseline](b2_1_live_baseline_20261104.md).

## Причина и изменение

На B2.1 raw Groq вернул `information/general/explain` для запроса загрузки; validated Observation сохранил его при точной цели «Как загрузить выписки…». TaskFrame был `general/explain`, Coordinator выбрал `grounded_information`, retrieval выбрал статью `directbank-all-accounts`, но conceptual gate отверг разделы и ответил об отсутствии объяснения. Версию/редакцию модель назвала как component, валидатор отклонил эти entities; точная версия оставалась в исходной task fact/query, но не была отдельным структурированным фактом. Ошибку не следует считать потерей уже подтверждённого структурированного поля.

В `app/dialogue_understanding.py` для точной подтверждённой цели с явной конструкцией «как + инфинитив действия» противоречивый `explain` заменяется на `unknown`, без угадывания конкретной операции и без изменения исходных фактов. Coordinator существующим механизмом направляет готовую задачу к техническому retrieval. Concept-формулировки и диагностические симптомы сохраняют прежнюю ветку. Это ограниченный распознаватель, не общее решение для всех языковых форм; `unknown` не доказывает operation compatibility. Проверки approved, SHA, scope, порядка, safety и существующий механизм operation compatibility не менялись; различение неподтверждённой операции остаётся ограничением. Для частей запроса без goal, иных форм и неоднозначностей успех не доказан.

Ответы не маркируют явно неполноту отсутствующей процедуры.

Вопрос: Что такое ДиректБанк и для чего он нужен?

Полный ответ:

> ДиректБанк – это банк, который работает полностью онлайн, без традиционных отделений. Он предназначен для удобного управления финансами: открытие и обслуживание счетов, проведение платежей, получение кредитов и инвестиций через интернет.

> Подтверждённого общего источника по этому вопросу в базе пока нет.

Raw `general/explain` → validated `general/explain` → TaskFrame `general/explain` → Coordinator `grounded_information`. `scenario_reason=general_knowledge_fallback`. understanding 200 / 1913 tokens, general_knowledge 200 / 402 tokens.

В №3 код правки не срабатывал: это `general/explain`, Coordinator правильно выбрал `grounded_information`. После поиска `_general_knowledge_fallback` сгенерировал определение онлайн-банка и его допустили проверки формы/безопасности и совпадения терминов; утверждение не подтверждено approved evidence и не отвечает надёжно на вопрос о сервисе 1С. Ключевое наблюдение — не доказана причина всех ошибок fallback или его новизна: текущая правка не затрагивает эту ветку. В рамках B2.2a она не изменена.
