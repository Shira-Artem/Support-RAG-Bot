# Переход АТОЛ Онлайн на ФФД 1.2: сначала проверьте интеграцию

## Область действия

Этот раздел касается перехода облачной кассы АТОЛ Онлайн на ФФД 1.2 для начала продаж маркированных товаров. Он не определяет выбор ФФД для каждого вида бизнеса, модели физической ККТ или другого сервиса.

## До подачи заявки

Сначала подтвердите техническую готовность интеграции к ФФД 1.2. Если касса подключена через банк или платёжного агрегатора, согласуйте с ним поддержку интеграции и порядок перехода. Для собственной интеграции обратитесь к разработчику. Не обещайте переход без предварительной проверки совместимости.

## Порядок, описанный АТОЛ Онлайн

После подтверждения условий подайте заявку в личном кабинете: «Изменение данных» → выберите компанию → «Изменить данные» → «Изменение ФФД» → «Перейти к редактированию» → заполните параметр перехода на ФФД 1.2 → отправьте заявку. Если продаются маркированные товары, отдельно включите соответствующий признак в параметрах магазина и в личном кабинете ФНС. После перехода отправляйте запросы регистрации чеков через API v5; для ФФД 1.05 источник указывает API v4.

Это описание производителя не подтверждает сроки обработки заявки, совместимость конкретного банка/агрегатора, версию конкретной интеграции или доступность перехода для данного договора. Эти условия уточняйте у интегратора и поддержки АТОЛ Онлайн.

## Необратимость и эскалация

После перехода на ФФД 1.2 возврат к ФФД 1.05 невозможен без замены фискального накопителя. До заявки согласуйте совместимость и последствия с интегратором, поддержкой и специалистом по ККТ. Не используйте старую формулировку «в любой момент» как обещание перехода без условий.

Официальные источники: [переход на ФФД 1.2](https://help.atol.online/article/22555) и [старое описание третьего шага](https://help.atol.online/article/12161).
