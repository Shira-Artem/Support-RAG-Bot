# Учёт операций по ЕНС при интеграции 1С с ФНС

## Границы по версиям

Для «1С:Бухгалтерии 8» версии 3.0.191 источник 1С описывал автоматический переход на начисления по данным ФНС при настроенной интеграции с Личным кабинетом ФНС. Режим включался с начала месяца обновления. Начисления отражались документами «Операции ЕНС»; при проведении регламентных и иных перечисленных в публикации документов прежние проводки начислений ЕНС не создавались, а соответствующие прежние проводки удалялись с начала месяца обновления. Для организаций без такой интеграции порядок не менялся.

Начиная с версии 3.0.194 способ учёта операций ЕНС указывается отдельно в настройках налогов и отчётов. Источник 1С описывает два режима: по данным принятой ФНС отчётности и по данным бухгалтерского учёта. Поэтому правило перехода 3.0.191 нельзя применять ко всем поздним версиям без проверки активного способа учёта.

## Что проверить до изменения

1. Уточните точный релиз конфигурации, включена ли интеграция с Личным кабинетом ФНС и какой способ учёта ЕНС выбран в этой версии.
2. Для обновления или переключения режима зафиксируйте месяц обновления, документы ЕНС и существующие проводки; сверьте их с данными ЛК ФНС.
3. До ручного восстановления, повторного начисления или удаления проводок получите решение бухгалтера. Не корректируйте учёт только ради совпадения итоговых сумм.
4. Если релиз старше 3.0.194, способ учёта неизвестен или проводки уже изменились неожиданно, остановитесь и передайте базу бухгалтеру/специалисту 1С.
