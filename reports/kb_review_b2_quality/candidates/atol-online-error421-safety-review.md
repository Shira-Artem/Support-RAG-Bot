# Ошибка 421: истёк таймаут проверки кода маркировки

## Предлагаемая замена только раздела 421

Ошибка указывает, что ответ ИСМ/ЦРПТ не получен за отведённое время. Перед повтором проверьте статус предыдущего запроса и убедитесь, что чек не зарегистрирован. Не создавайте повторный запрос с теми же идентификаторами вслепую: неизвестный результат после сетевого обрыва отличается от однозначного отказа.

Спецификация API АТОЛ Онлайн v5, ФФД 1.2, описывает `ism_optional=true` как технический вариант регистрации чека при таймауте проверки без ответа ИСМ. Эта возможность API сама по себе не подтверждает допустимость продажи конкретного маркированного товара, статус кода, группу товара, обязательность разрешительного режима или право обходить проверку в данном случае. Поэтому не рекомендовать клиенту включать параметр автоматически.

В справке АТОЛ для ошибки 421 описан повтор запроса с новым `external_id`. Повторяйте только после проверки, что исходный фискальный документ не зарегистрирован; если после сетевого сбоя статус запроса неизвестен, сначала выясните его у интегратора/АТОЛ. Отдельный статус `fail` («Таймаут») в той же справке имеет собственную ветку: АТОЛ указывает, что такой запрос не зарегистрирован, и описывает повтор с новым `External_ID` в течение 24 часов; после этого срока — чек коррекции. Не смешивайте статус `fail` («Таймаут») с любым случаем отсутствия ответа. Ни этот повтор, ни новый идентификатор сами по себе не разрешают `ism_optional=true`.

Передайте специалисту по ККТ/маркировке тип товара, код ошибки, request/external_id, ответ API, статус фискального документа и результат обращения к ИСМ. Повторный запрос или изменение параметра выполняйте только после определения, что произошло с исходным чеком и что разрешено для этой товарной группы.

Этот кандидат предназначен только для замены раздела об ошибке 421 в существующей approved-карточке `atol-online-22561-fn-and-marking-errors-116-414-421-148`. Он не заменяет секции ошибок 116, 414 и 148 и не должен индексироваться как самостоятельная инструкция. Официальный API v5 PDF (ФФД 1.2, 198 стр.) повторно открыт 16.11.2026; таблица `ism_optional` находится на стр. 14–15. На соседних страницах отдельно описаны `use_tspiot` и `permissive_mode`; эти параметры нельзя трактовать как взаимозаменяемые. Статья поддержки АТОЛ #22561, повторно прочитанная 18.11.2026, подтверждает симптом/ошибку 421 и описывает вариант запроса, но не решает правовую применимость. Точная версия клиентского endpoint, правомерность для товарной группы, разрешительный режим и статус запроса подтверждаются интегратором/специалистом до любого изменения запроса. Кандидат — только ограниченный вариант раздела, не самостоятельная инструкция.


## Источники и границы подтверждения

- [Официальная спецификация АТОЛ Онлайн API v5 (ФФД 1.2), PDF](https://atol.online/upload/iblock/e8a/f2y5d3lbu77u5blqbv1qoxyk9lh0n5p3/API%20%D1%81%D0%B5%D1%80%D0%B2%D0%B8%D1%81%D0%B0%20%D0%90%D0%A2%D0%9E%D0%9B%20%D0%9E%D0%BD%D0%BB%D0%B0%D0%B9%D0%BD_v5.pdf) — страницы 14–15/198 описывают `ism_optional`, а также отдельные параметры `use_tspiot` и `permissive_mode`. Это техническое поведение протокола; дата/номер выпуска конкретного PDF не указаны.
- [Официальная статья АТОЛ Онлайн о возможных ошибках, включая 421](https://help.atol.online/article/22561) — описывает timeout ИСМ и обработку параметра в статье поддержки; сама по себе не устанавливает юридическую допустимость для каждой группы маркированных товаров.

Не проверены релиз клиентского API, endpoint конкретного клиента, товарная группа и актуальные требования к разрешительному режиму. Перед изменением запроса интегратор/специалист подтверждает статус исходного чека и допустимый порядок действий.
