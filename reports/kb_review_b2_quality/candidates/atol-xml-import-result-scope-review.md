# Результат загрузки XML-реестра: что подтверждено

Официальная краткая инструкция АТОЛ Онлайн говорит, что после отправки XML-реестра на странице отображается информация об обработке **документа**. В доступном тексте нет описания, подтверждающего отдельный результат и перечень ошибок **по каждому чеку внутри реестра**. Полная PDF-инструкция по ссылке из статьи при проверке не загрузилась; не обещайте такую детализацию, пока АТОЛ не подтвердит её для актуального кабинета.

Если требуется проверить, какие чеки уже зарегистрированы ККТ, официальная статья АТОЛ о «Журнале чеков» подтверждает просмотр зарегистрированных чеков и открытие подробной информации по каждому чеку. Это проверка зарегистрированных фискальных документов, а не подтверждение результата обработки каждого элемента исходного XML-реестра. Статья указывает, что журнал показывает последние две недели; для более раннего периода описан заказ выгрузки в архиве чеков.

Не загружайте боевой реестр без предварительной проверки на дубли и соответствие выбранному ФФД. Отсутствие ошибки загрузки не гарантирует, что каждый чек из файла сформирован и зарегистрирован.

## Источники и ограничение

- [Как формировать чеки через XML-файл, АТОЛ Онлайн](https://help.atol.online/article/11250): после отправки реестра страница показывает информацию об обработке документа; полная PDF-инструкция дана отдельной ссылкой и при этой проверке недоступна.
- [Как выгрузить чеки в разделе «Журнал чеков», АТОЛ Онлайн](https://help.atol.online/article/22560): позволяет просматривать зарегистрированные чеки, открывать детализацию по каждому зарегистрированному чеку и заказывать архивную выгрузку за период более двух недель.

Версия кабинета и фактическая детализация результата обработки XML не подтверждены. Перед заменой текста в approved-карточке нужно получить полную инструкцию или письменное подтверждение поддержки АТОЛ. Candidate не является самостоятельной статьёй и не переносится в KB автоматически.
