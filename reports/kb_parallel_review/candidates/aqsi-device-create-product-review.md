# aQsi: безопасное заполнение карточки товара

## Вопрос
Какие сведения нужны при добавлении товара в каталог кассы aQsi?

## Что подтверждает инструкция производителя

1. В разделе «База товаров» выберите действие «Добавить/товар». Штрихкод можно считать встроенным сканером через кнопку «Сканировать» или заполнить вручную.
2. Статья перечисляет поля названия, артикула, категории, признака предмета расчёта, способа расчёта, ставки НДС, единицы измерения и цены. Выбранная категория может подставлять НДС и единицу измерения; проверьте их по настройкам организации и товара.
3. Включайте признак маркированного товара и тип маркировки только для подтверждённого случая. Если нужно применять дробную продажу маркированного товара, поле количества в упаковке используется как знаменатель. Для весового маркированного товара производитель указывает оставить значение по умолчанию 1.
4. В инструкции также перечислены флаги закупки у населения и запрета возврата позиции, а также код товара для ОФД и ограничение цены. Их смысл и необходимость для конкретного товара уточняйте у ответственного за каталог/учёт.

## Ограничения

Текст производителя не задаёт безопасные значения НДС, признаков расчёта, маркировки или агентских реквизитов для конкретного товара. Не выбирайте их наугад и не меняйте существующий каталог без полномочий владельца данных. Статья не раскрывает точную модель, версию приложения и кнопку сохранения в доступном тексте; сверяйте актуальный экран с инструкцией для модели.

## Передать специалисту

Если неизвестны НДС, товарный признак, код маркировки, единица/вес или настройки возврата — согласуйте карточку с бухгалтером и администратором каталога. Для отсутствующих полей или отличающегося экрана проверьте модель и версию ПО через поддержку aQsi.
