# ТС ПиОТ: определить модуль до диагностики отказа

## Минимальное уточнение
Спросить производителя кассы, конкретный модуль ТС ПиОТ/ЛМ ЧЗ, версию, точный текст/код отказа и возникает ли отказ на одной или разных марках. Не запрашивать токен, логин/пароль или полный код маркировки.

## Что подтверждено
Публичная документация Эвотор описывает API конкретной «Цифровой кассы» для проверки кода через модуль ТС ПиОТ. Это API-интеграция для разработчика/кассы и не универсальная инструкция по установке или диагностике всех модулей. Источник сообщает, какие поля ответа API описаны; он не подтверждает пользовательские меню, совместимость других производителей или конкретную причину отказа.

## Безопасная ветка и остановка
Можно только собрать название продукта/модуля, версии и безопасное сообщение ошибки. Если модуль — иной производитель, в API не найдено описание пользовательского действия, либо требуется токен/изменение настройки — остановиться и передать специалисту. Не выдавать команды из developer API как действия пользователя.

## Передать специалисту
Модель ККТ, ПО/версия, изготовитель/версия модуля, точный безопасный ответ/код, одна или несколько товарных позиций и время события; без токенов и кодов маркировки.
