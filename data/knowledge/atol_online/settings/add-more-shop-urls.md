# Как добавить ещё один интернет-магазин к кассе АТОЛ Онлайн

## Вопрос пользователя
Одна облачная касса нужна для двух сайтов. Как добавить второй?

## Что проверено по инструкции производителя
1. В ЛК АТОЛ Онлайн: «Изменение данных» → выбрать компанию → «Изменить данные» → «Параметры магазина» → «Перейти к редактированию».
2. Добавьте URL. В поле «Укажите новое место расчётов (URL магазина)» перечислите адреса через точку с запятой (;) без пробела. Ограничение: общая длина адресов всех сайтов — не более 256 символов. Все сайты должны принадлежать одной организации или ИП.
3. Отправьте заявку. Нажмите «Сохранить и отправить заявку на изменение» → подтвердите отправку. Дождитесь письма об успешном выполнении.
4. Перерегистрируйте кассу в ФНС (обязательно): ЛК ФНС → «Мои кассы» → нажмите на РНМ кассы → «Перерегистрировать» → «Перерегистрация по иным причинам» → в поле «ККТ используется для расчётов в информационно-телекоммуникационной сети Интернет» добавьте новые адреса через ; без пробела → «Подписать и отправить».

## Важное ограничение / передача специалисту
Перерегистрация в ФНС юридически значима; её следует поручать уполномоченному специалисту. Ограничения на перечень URL уточняйте в текущем интерфейсе.

> Область применения — облачные кассы АТОЛ Онлайн, если не указано иное.
