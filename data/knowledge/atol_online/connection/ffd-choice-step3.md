# Как выбрать ФФД 1.05 или 1.2 на третьем шаге АТОЛ Онлайн

## Вопрос пользователя
Какую версию ФФД выбрать при подключении облачной кассы АТОЛ Онлайн?

## Что проверено по инструкции производителя
1. Если продаёте маркированный товар — только ФФД 1.2.
В источнике: «в обязательном порядке выберите версию ФФД 1.2» (L12–L13).
2. Если маркировки нет — ФФД 1.05.
В источнике: «Если маркированных товаров у вас нет, укажите версию ФФД 1.05» (L13–L14).
3. Если не уверены — выбирайте 1.05.
В источнике: «Если вы не уверены в выборе, укажите версию ФФД 1.05. Перейти на версию 1.2 вы сможете в любой момент» (L14–L16).
4. Переход на 1.2 возможен позже — в любой момент, без ограничений по третьему шагу (L15–L16).

## Контекст третьего шага (из того же источника)
На третьем шаге также заполняются:
1. URL-адрес: для интернет-магазина — ссылка на сайт; для такси — «Такси»; для ЖКХ — ссылка на СБИС или «ЖКХ»; для вендинга — «Вендинг»; для курьеров — «Курьеры»; для оплаты на расчётный счёт — фактический адрес организации (L4–L11).
2. ФН: для ОСН обычно 15 месяцев, для УСН/ПСН — 36 месяцев (L20–L21).
3. Параметры торговли: проставить по роду деятельности; параметр «ККТ входит в состав автоматического устройства для расчётов» уже проставлен, менять не нужно (L22–L26).
4. Калькулятор ККТ: если меньше 6000 транзакций в сутки — достаточно 1 кассы; если больше — обратиться к менеджеру (L27–L31).

## Важное ограничение / передача специалисту
Не устанавливайте ФФД автоматически: переход или неверный выбор может повлиять на регистрацию ККТ и интеграцию. Требуется специалист.

> Область применения — облачные кассы АТОЛ Онлайн, если не указано иное.
