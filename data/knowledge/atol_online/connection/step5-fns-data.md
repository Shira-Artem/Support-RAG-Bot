# Шаг 5 подключения АТОЛ Онлайн: сведения для регистрации в ФНС

## Вопрос пользователя
Какие данные понадобятся для регистрации облачной ККТ АТОЛ Онлайн в ФНС?

## Что проверено по инструкции производителя
1. В течение рабочих суток после оплаты в ЛК АТОЛ Онлайн становится доступен пятый шаг. На нём указаны все данные по кассе, которые потребуются для регистрации в ФНС (L4–L6).
2. Для входа в ЛК ФНС используйте Яндекс Браузер или Chromium-Gost, установите CryptoPro Extension и КриптоПро CSP (L11–L17).
3. Данные для заявления в ФНС (раздел «Кассы» → «Зарегистрировать вручную»):
    - Адрес установки (применения) ККТ: Волгоградский проспект, дом 42, корпус 9 (L20–L21).
    - Наименование места установки ККТ: ЦОД (L21–L22).
    - Модель ККТ: АТОЛ 42ФС или Казначей ФА (L22–L23).
    - Заводской номер ККТ: из ЛК АТОЛ Онлайн (L23–L24).
    - Название ФН и заводской номер: точь-в-точь как в ЛК АТОЛ Онлайн (L24–L26).
    - Флажок «ККТ входит в состав автоматического устройства для расчетов» → «Добавить»: номер АУ (начинается с KZN или KKT); адрес установки ККТ — Волгоградский проспект, дом 42, корпус 9; место установки ККТ — ЦОД (L26–L31).
    - Для интернет-магазина: флажок «ККТ используется для расчетов в информационно-телекоммуникационной сети Интернет» и URL-адрес сайта (L31–L33).
    - ОФД: выбранный на втором шаге регистрации в ЛК АТОЛ Онлайн (L33–L35).
4. Нажмите «Подписать и отправить». Если у вас есть менеджер — обратитесь к нему за помощью (L35–L36).

## Важное ограничение / передача специалисту
Регистрация в ФНС — юридически значимое действие. Не подставляйте типовой адрес ЦОД или флажки из чужого примера; всё необходимо сверить по конкретной ККТ и текущему порядку ФНС.

> Область применения — облачные кассы АТОЛ Онлайн, если не указано иное.
