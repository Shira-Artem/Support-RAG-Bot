# Тег 1212 / payment_object для ФФД 1.05 АТОЛ Онлайн

## Вопрос пользователя
Что значит payment_object в API чека ФФД 1.05?

## Что проверено по инструкции производителя
Поле payment_object соответствует признаку предмета расчёта (тег 1212) и показывает, за какой объект проводится расчёт: например, товар, подакцизный товар, работа, услуга, имущественное право и другие виды. Значение должно соответствовать фактической операции и конкретному ФФД. При ошибке сравните значение, которое посылает ваша интеграция, с документированным справочником для ФФД 1.05.

## Важное ограничение / передача специалисту
Не копируйте на ФФД 1.05 перечень признаков ФФД 1.2; для спорных значений и налоговых случаев привлекайте специалиста.

> Область применения — облачные кассы АТОЛ Онлайн, если не указано иное.
