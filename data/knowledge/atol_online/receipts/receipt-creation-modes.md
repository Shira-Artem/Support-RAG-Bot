# Три способа формирования чеков в АТОЛ Онлайн

## Вопрос пользователя
Чем отличается ручная отправка чеков от автоматической и XML-загрузки?

## Что проверено по инструкции производителя
1. Ручное формирование. В разделе «Формирование чеков 1.05/1.2» можно сформировать чеки типов: приход, возврат прихода, коррекция прихода, расход, возврат расхода, коррекция расхода.
2. Автоматическое формирование. Нужно связать облачную кассу с сервисом, через который принимается оплата: CMS, CRM, платёжные системы, интернет-эквайринг. Затем — настроить интеграцию. Также можно разработать собственную интеграцию.
3. Формирование через XML-файл. Загрузка XML позволяет за раз сформировать большое количество чеков без ручного заполнения данных по каждому.

## Важное ограничение / передача специалисту
Один и тот же платёж не должен быть фискализирован повторно из разных каналов. Перед массовой загрузкой сверить историю чеков.

> Область применения — облачные кассы АТОЛ Онлайн, если не указано иное.
