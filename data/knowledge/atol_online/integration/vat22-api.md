# Ставки НДС 22% и 22/122 в API АТОЛ Онлайн

## Вопрос пользователя
Как передавать новую ставку НДС через API АТОЛ Онлайн?

## Подтверждённые сведения
В опубликованной документации API v4 и v5 для чека предусмотрены значения vat22 и vat122. Фискализация использует данные, которые передаёт внешняя платёжная система или CMS: обновление одной только облачной кассы недостаточно, если интегратор отправляет старые значения.

## Важно / когда передать специалисту
Перед сменой ставки проверьте актуальную версию API, релиз интегратора и правомерность выбранной ставки с бухгалтером.

> Материал относится к облачному сервису «АТОЛ Онлайн», а не ко всем физическим моделям АТОЛ. Черновик: проверить у профильного специалиста перед публикацией.
