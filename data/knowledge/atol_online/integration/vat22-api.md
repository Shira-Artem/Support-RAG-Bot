# Ставки НДС 22% и 22/122 в API АТОЛ Онлайн

## Вопрос пользователя
Как передавать новую ставку НДС через API АТОЛ Онлайн?

## Подтверждённые сведения
1. Новые значения в API v4 и v5. В метод регистрации документа в параметры vats и vat добавлены:
    - vat22 — ставка НДС 22%;
    - vat122 — расчётная ставка НДС 22/122.
2. Где смотреть документацию.
    - API v4 (ФФД 1.05): http://atol.online/api_v4;
    - API v5 (ФФД 1.2): http://atol.online/api_v5.
3. Сроки выпуска.
    - Боевая среда: обновление, позволяющее принимать новые ставки, запланировано до 31.12.2025.
    - Тестовая среда: уже обновлена и готова к приёму запросов с vat22 и vat122.
4. Сервис АТОЛ Онлайн фискализирует запросы, которые приходят из внешних систем. После выхода обновления обратитесь к разработчикам вашего сайта и техническим специалистам платёжной системы — они помогут настроить передачу данных с учётом новых ставок.

## Важно / когда передать специалисту
Перед сменой ставки проверьте актуальную версию API, релиз интегратора и правомерность выбранной ставки с бухгалтером.

> Материал относится к облачному сервису «АТОЛ Онлайн», а не ко всем физическим моделям АТОЛ. Черновик: проверить у профильного специалиста перед публикацией.
