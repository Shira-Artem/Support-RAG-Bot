# Как тестировать прямую API-интеграцию с АТОЛ Онлайн

## Вопрос пользователя
Как разработчику проверить интеграцию облачной кассы по API?

## Подтверждённые сведения
У АТОЛ Онлайн есть документация API и отдельная тестовая среда. В справке API v5 соотнесён с ФФД 1.2, а API v4 — с ФФД 1.05. Сначала уточните используемый формат фискальных данных и тип внешней системы, затем проводите проверку в тестовой среде без реальных фискальных операций.

## Важно / когда передать специалисту
Изменения протокола и переход ФФД требуют согласования с разработчиком интеграции.

> Материал относится к облачному сервису «АТОЛ Онлайн», а не ко всем физическим моделям АТОЛ.
