# Переход облачной кассы АТОЛ Онлайн на ФФД 1.2

## Вопрос пользователя
Как перевести АТОЛ Онлайн с ФФД 1.05 на 1.2?

## Что проверено по инструкции производителя
1. Проверьте техническую готовность интеграции.
    - Если вы подключены через банк или платёжного агрегатора — уточните, готова и поддерживается ли у них интеграция с АТОЛ Онлайн и как перейти на ФФД 1.2.
    - Если у вас собственная интеграция — обратитесь к вашим разработчикам. Документация по API v5 для работы на ФФД 1.2: https://atol.online/api_v5.
2. Подайте заявку в ЛК АТОЛ Онлайн.
    - Перейдите в раздел «Изменение данных».
    - Выберите нужную компанию → «Изменить данные».
    - Выберите раздел «Изменение ФФД» → «Перейти к редактированию».
    - Заполните параметр «Перевести на ФФД 1.2».
    - Нажмите «Сохранить и отправить заявку на изменение».
3. Если реализуете маркированные товары.
    - Перейдите в раздел «Параметры магазина».
    - Выберите интернет-магазин → установите признак «Маркированные товары» → «Сохранить и отправить заявку на изменение».
    - Вручную внесите признак торговли маркированными товарами в Личном кабинете ФНС.
4. После подачи заявки — перейдите на API v5. Отправка запросов на регистрацию чеков должна производиться по протоколу API v5 (ФФД 1.2). При работе на ФФД 1.05 используется протокол API v4.

## Важно / когда передать специалисту
Переход затрагивает регистрацию ККТ и необратим без замены ФН. Самостоятельно не запускайте смену без инженера.

> Материал относится к облачному сервису «АТОЛ Онлайн», а не ко всем физическим моделям АТОЛ.
