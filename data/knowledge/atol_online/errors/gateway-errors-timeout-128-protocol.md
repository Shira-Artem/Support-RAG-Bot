# Ошибки timeout, [128] и протокола группы АТОЛ Онлайн

## Вопрос пользователя
Что делать при fail/timeout, ошибке 128 или несовпадении токена группы?

## Подтверждённые сведения
1. Статус «Таймаут» (fail). Запрос не был зарегистрирован.
    - Отправьте запрос повторно с новым External_ID в течение 24 часов с момента получения статуса.
    - Если прошло более 24 часов — сформируйте чек коррекции.
    - Если чек уже отправлен повторно — не предпринимайте дополнительных действий.
2. Ошибка «[128] Некорректная сумма налога» в чеке коррекции. Причина: при ставке «Без НДС» в поле «Сумма НДС» передано 0 вместо суммы расчёта по чеку. Решение: при ставке «Без НДС» указывайте в поле «Сумма НДС» сумму расчёта по чеку без НДС. Пример: для чека на 100 руб. — передать 100. Обратитесь к специалистам интернет-эквайринга для корректировки запроса и повторной отправки.
3. «Код группы не поддерживает данную версию протокола». Причина: запрос идёт в группу касс, работающую по другому протоколу. Решение: проверьте настройки интеграции во внешней системе. При сложностях — обратитесь к техническим специалистам внешней системы.
4. «Код группы, указанный в запросе, не соответствует токену». Причина: запрос отправляется по протоколу, не соответствующему настройкам кассы, или указан некорректный идентификатор группы. Решение:
    - Проверьте корректность интеграции кассы АТОЛ Онлайн с внешней системой.
    - Скачайте актуальные параметры в ЛК АТОЛ Онлайн → «Мои компании» → «Настройки интегратора».
    - В файле в блоке access указаны три параметра: group_code, password, login.
    - Укажите эти параметры в соответствующих полях ЛК вашей внешней системы.

## Важно / когда передать специалисту
Для таймаута не выполняйте «слепой» повтор без проверки статуса — риск дублирования. Сначала убедитесь, что предыдущий запрос действительно не зарегистрирован (по External_ID или в ЛК). Для ошибок группы различайте два случая: несовпадение протокола и неверный group_code — решения разные.

> Материал относится к облачному сервису «АТОЛ Онлайн», а не ко всем физическим моделям АТОЛ.
