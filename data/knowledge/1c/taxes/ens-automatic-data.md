# Начисления на ЕНС по данным ФНС в 1С

## Вопрос
Почему в 1С начисления ЕНС появляются автоматически или не совпадают с нашими данными?

## Подтверждённое изменение
С версии 3.0.191 начисление задолженности по уплате налогов на ЕНС может выполняться по данным ФНС, если у организации настроена интеграция с личным кабинетом ФНС.

## Уточняющие вопросы
1. Точная версия 1С и включён ли сервис синхронизации с ФНС.
2. Отчётность принята налоговой или ещё ожидает обработки?
3. На какую дату сравниваются данные ФНС и 1С?
4. Нет ли вручную введённых параллельных операций по ЕНС?

## Ограничение
Суммы начислений нельзя исправлять в 1С только ради совпадения с ожиданиями: сверить их с официальными данными и передать расхождение бухгалтеру.
