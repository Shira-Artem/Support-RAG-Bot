# Документ «Операции ЕНС» вместо «Корректировка ЕНС»

## Вопрос
Почему в 1С не найти документ «Корректировка ЕНС»?

## Подтверждённое изменение
С версии 3.0.191 прежнее название документа «Корректировка ЕНС» заменено на «Операции ЕНС». Документ теперь способен включать несколько видов начислений по ЕНС.

## Диагностика
1. Спросить версию «1С:Бухгалтерии 8».
2. Попробовать искать название «Операции ЕНС» вместо прежнего.
3. Проверить раздел налогов и доступные пользователю роли.
4. Перед созданием корректировки выяснить, не приходят ли начисления автоматически из интеграции с ФНС.

## Безопасность
Само наличие документа не означает, что нужно вводить ручную корректировку: операция меняет налоговый учёт и требует согласования с бухгалтером.
