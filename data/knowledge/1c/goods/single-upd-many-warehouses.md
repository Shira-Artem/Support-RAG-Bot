# Один УПД поставщика, поступление товара на несколько складов

## Вопрос
Можно ли оформить поступление по одному УПД, если товар физически поступил на разные склады?

## Подтверждённая возможность
Начиная с версии 3.0.188 в «1С:Бухгалтерии 8» один документ поступления может отражать один УПД поставщика и несколько приходных ордеров М-4 для разных складов — без дополнительных перемещений товаров между складами. Сценарий рекомендован организациям, где товары в рознице оцениваются по стоимости приобретения; в версии КОРП склады в одном поступлении должны находиться в одном обособленном подразделении.

## Диагностика
1. Уточнить версию конфигурации — функция появилась в 3.0.188.
2. Включить настройку «Поступление на несколько складов»: Простой интерфейс — «Настройки → Функциональность → Запасы»; Полный интерфейс — «Главное → Настройки → Функциональность → Запасы».
3. В документе "Поступление товаров" в поле "Склад" выбрать "В списке". При добавлении товаров отдельно добавляем партии товаров для разных складов.
4. Сверить номенклатуру и общее количество по УПД с фактическим поступлением на каждый склад; проверить отсутствие дублей поступления по одному первичному документу.
5. Учесть ограничения: в версии КОРП склады должны быть в одном обособленном подразделении; обмен в формате EnterpriseData текущей версией не передаёт информацию о нескольких складах в одном поступлении.
6. По документу распечатывается приходный ордер М-4 для каждого склада; дополнительные расходы распределяются по товарам по складам.
7. При корректировке такого поступления склады заполняются как в исходном документе — изменить их нельзя.
8. Выяснить используемую в организации схему оформления первичных документов, если требуется распределение товаров по складам.

## Эскалация
Некорректные складские остатки, закрытые периоды или расхождения по маркированным товарам требуют специалиста по учёту/1С.
