# 1С-ЭПД: обмен транспортными ЭПД и ошибка «контрагент не найден»

## Вопрос
В 1С-ЭПД ошибка «контрагент в хранилище не найден» при передаче транспортного документа. Нужны ли приглашения?

## Подтверждённое разъяснение
Для обмена электронными перевозочными документами (ЭПД), включая роуминг, приглашение контрагента не требуется: документ отправляется адресату. Оператор получателя должен быть включён в реестр операторов ГИС ЭПД Минтранса.

## Безопасная диагностика
1. Уточнить, что используется именно 1С-ЭПД, а не обычный 1С-ЭДО для УПД.
2. Записать полную ошибку и идентификаторы участников обмена без публикации персональных сведений.
3. Проверить оператора получателя по актуальному реестру.
4. При сообщении «контрагент в хранилище не найден» передать обращение в поддержку 1С-ЭПД для проверки/добавления идентификатора.

## Важно
Правила приглашений для обычного ЭДО и транспортного ЭПД различаются. Нельзя смешивать эти процессы.
