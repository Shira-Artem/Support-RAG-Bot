# Загрузка выписки другого банка через посредника в 1С:ДиректБанк

## Вопрос
Банк не подключён к прямому обмену с 1С:ДиректБанк. Можно ли получать его выписки через другой банк?

## Подтверждённая возможность
С версии 3.0.203 предусмотрена загрузка выписок из других банков через банк-посредник. Список доступных банков определяется конкретным посредником. На текущий момент такую интеграцию поддерживает ООО «Банк Точка».

## Диагностика
1. Уточнить конфигурацию и версию — возможность относится к 3.0.203 и новее.
2. Проверить, есть ли у организации настроенная поддерживаемая связка с посредником.
3. Проверить список доступных банков, банковские счета и права на обмен.
4. Сначала требуется выполнить в личном кабинете банка‑посредника настройку интеграции с другим банком.
5. После настройки интеграции в кабинете банка-посредника можно переходить к настройке в «1С:Бухгалтерии 8». Простой интерфейс: меню «Организация». Полный интерфейс: меню «Главное – Настройки – Организации». В поле "Банк" указать банк, по которому доступна загрузка выписок через банк-посредник. Нажать "Подключить обмен с банком", чтобы подключить загрузку выписок через банк-посредник. В окне "Подключение к 1С:ДиректБанк" выбрать "Загрузка банковской выписки через ООО «Банк Точка»". В окне "Доступ для обмена" указать логин и пароль, полученные в банке-посреднике. После этого должно появиться подтверждение о подключении банковских выписок.
6. Если у организации несколько счетов в банке, то будет подключено получение банковских выписок через банк-посредник по всем счетам. Если по банку была ранее создана отдельная прямая настройка обмена, то она будет помечена как недействующая. Также подключение других банков можно выполнить из настройки обмена с банком-посредником. Простой интерфейс: меню «Настройки → Основное → Настройки программы → Обмен электронными документами → Обмен с банками → Настройки обмена с банками». Полный интерфейс: меню «Администрирование → Настройки программы → Обмен электронными документами → Обмен с банками → Настройки обмена с банками». Вкладка "Дополнительные банки" → "Добавить" → "Выберите банк".
7. Для загрузки банковских выписок открыть "Обмен с банками" → вкладка "Загрузка выписки из банка" → "Запросить через 1С:ДиректБанк" → в окне "Доступ для обмена" указать пароль и логин, полученные в банке-посреднике → "Загрузить"
8. Если банк отсутствует в списке, не обещать доступность интеграции; предложить согласовать иной поддерживаемый способ загрузки.

## Ограничение
Это функция банковского обмена, а не универсальный парсер любых выписок.

## Когда нужен специалист
Не получилось выполнить интеграцию или загрузку, либо пользователь использует другого посредника (в документации указан только ООО «Банк Точка»), и инструкция оказалась неактуальна.
