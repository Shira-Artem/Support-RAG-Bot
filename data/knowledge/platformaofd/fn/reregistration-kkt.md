# Перерегистрация ККТ через Платформу ОФД

## Подача заявления

1. Нажмите кнопку **«+ Перерегистрация»** — загрузится форма подачи заявления.
2. **Выберите кассу** из выпадающего списка. Если кассы нет в личном кабинете (например, при перерегистрации из другого ОФД), внесите её данные вручную. Нажмите **«Далее»**.
3. В блоке **«Текущие сведения о кассе»** отображается полная информация. Если нужно что-то изменить, нажмите **«Изменить данные кассы»** — после правок откроется новая заявка на перерегистрацию.
4. Выберите **одну или несколько причин** перерегистрации.

## Новые сведения (включая замену ФН)

- Если касса ранее была в личном кабинете, после формирования на ней **отчёта о закрытии** данные можно заполнить **автоматически** по кнопке.
- Если касса только добавляется в личный кабинет ОФД, данные из отчёта о закрытии заполняются **вручную**.
- Если **ФН неисправен**, выберите соответствующий чекбокс.
- Введите данные **нового фискального накопителя**.
- Сформируйте на кассе **отчёт об изменении параметров**.
- Если касса ранее была в личном кабинете, после формирования отчёта об изменении ФН данные можно заполнить **автоматически** по кнопке.
- Нажмите **«Отправить»**.

## Подписание и статус

- Подпишите заявку **КЭП организации**.
- Статус заявки отслеживается в меню. При подтверждении от ФНС перерегистрация считается успешной.
- Зайдя в заявку, можно **загрузить документ «Карточка перерегистрации ККТ»**.
- Если ФНС отклонила заявку, **причину отказа можно увидеть в самой заявке**.
Этот конспект не заменяет полную инструкцию и проверку регистрационных реквизитов специалистом.
