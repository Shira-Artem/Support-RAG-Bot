# Поиск фискального документа в Платформе ОФД

## Поля поиска

В кабинете клиента откройте раздел «Чеки». Источник описывает фильтры по периоду пробития, типу документа, магазину и кассе. Для точного поиска можно использовать номер ФД или фискальный признак с чека. Поиск по кассе допускает её название или регистрационный номер.

## Как читать статус

«Принят» означает приём без ошибок, «Принят с предупреждением» — приём с выявленными замечаниями. «В карантине» связан с незавершённой регистрацией ККТ, а «Отказ в приёме» — с ошибками документа. При спорном статусе зафиксируйте номер ФД и детали проверки, затем направьте их специалисту; один статус без расшифровки ошибки не даёт основания исправлять кассу наугад.
