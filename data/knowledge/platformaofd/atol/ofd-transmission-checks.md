# ККТ АТОЛ не передаёт документы в Платформу ОФД

## Что проверить

1. **Заводской номер ФН** в личном кабинете ОФД должен совпадать с паспортными данными ККТ и ФН.
2. **Доступность портов ОФД**: **21101 / 19081 / 31101** (входящие и исходящие).
3. **Соединение ККТ с интернетом**.
4. **Служба Ethernet over USB (EoU)** — если используется, должна быть запущена; проверить её настройки и log-файлы передачи.
5. **Диагностика связи с ОФД** — запускается с ККТ или через драйвер.

## Параметры для сверки

|      |   Рабочий сервер       |    Тестовый сервер     |
|------|------------------------|------------------------|
| URL  | `ofdp.platformaofd.ru` | `ofdt.platformaofd.ru` |
| IP   | `185.170.204.91`       | `185.170.204.85`       |
| Порт | `21101`                | `19081`                |

## Регистры и журналы

- В менеджере регистров АТОЛ прочитать регистр **«43. Ошибка ОФД (сеть)»**.
- Расшифровку кода ошибки сверять с документацией производителя ККТ.
- При необходимости изучить журнал передачи.

## Важно

- Если с даты первого непереданного документа прошло **30 дней**, ФН блокируется — чеки пробить нельзя, пока документы не уйдут оператору.
- Рекомендуемая версия драйвера — **не ниже 8.12**.
- При **NAT-соединении** рекомендуется выделенный канал связи ККТ с интернетом.
- Документ относится к ККТ АТОЛ в целом; путь к настройкам может отличаться по модели.
