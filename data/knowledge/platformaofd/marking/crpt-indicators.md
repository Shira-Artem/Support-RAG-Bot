# Раздел ЦРПТ в контроле нарушений

## Разрешительный режим

**Индикатор 1. «Проверка на кассе не проводилась»**
Отражает случаи реализации товаров с КМ без проверки на кассе (Постановление Правительства № 1944). **Важно:** в текущей версии сервиса отражаются **все реализации без проверки КМ на кассе, вне зависимости от того, попадает товарная группа под действие РР или нет**. В дальнейшем в индикатор будут попадать только КМ по соответствующим товарным группам.
**Источник данных:** тег **1265** «значение отраслевого реквизита» и тег **1264** «номер документа основания» (факт и причина проведения проверки).
**Цвет:** жёлтый — найдены КМ без проверки (пользователю необходимо убедиться, что нарушения отсутствуют); зелёный — все КМ прошли проверку.
**Переход:** при нажатии на кнопку — отчёт «Чеки с маркировкой по ФФД 1.2» с преднастроенными фильтрами «Период».

**Индикатор 2. «Проверка кода маркировки на кассе»**
Показывает количество КМ, для которых была проведена проверка. Носит **информационный характер**.
**Переход:** при нажатии на кнопку — отчёт «Чеки с маркировкой по ФФД 1.2».

## Уведомительный режим

**Индикатор «Проверка кода маркировки в чеке»**
Отражает результаты форматно-логического контроля КМ при передаче фискального документа «Запрос о коде маркировки». Состоит из состояний: **ошибки при ФЛК**; **отсутствие проверки** (например, по техническим причинам).
**Цвет:** жёлтый — есть КМ с отклонениями, требуется проверить корректность; зелёный — отклонений нет.

## Фильтры

Период переключается тумблером: **«30 календарных дней»** (выбран по умолчанию) или **«вчера»**. Тумблер **«Только требующие внимания»** оставляет на странице только индикаторы с отклонениями.

## Рекомендации и последствия

Для каждого индикатора предусмотрены блоки: **«Рекомендации»** — перечень действий для устранения причины отклонения; **«Последствия при нарушении»** — возможные последствия, включая штрафы и проверки. При нажатии на кнопку карточки индикатора выполняется переход в **«Мониторинг»** или соответствующий отчёт.

## Ограничения

Жёлтый индикатор означает необходимость проверить конкретные чеки и коды маркировки. Статья отдельно предупреждает, что индикатор отсутствия проверки на кассе в текущей версии сервиса может включать товарные группы, для которых разрешительный режим не обязателен. Поэтому один цвет панели не является достаточным основанием для вывода о нарушении.
