# ККТ Штрих-М не передаёт чеки в Платформу ОФД

## 1. Базовая сверка

- **Заводской номер ФН** в личном кабинете «Платформа ОФД» должен совпадать с паспортом ККТ (ФН).
- Проверьте **доступность портов 21101 / 19081** для входящих и исходящих подключений — на сетевом оборудовании и через запрос к провайдеру.
- Проверьте **доступность портов, используемых непосредственно ККТ** (уточняется у производителя ККТ).
- При **NAT-сети** рекомендуется выделенная линия для ККТ или компьютера, к которому она подключена.

## 2. Параметры серверов

| Параметр           | Рабочий сервер         | Тестовый сервер                  |
|--------------------|------------------------|----------------------------------|
| URL                | `ofdp.platformaofd.ru` | `ofdt.platformaofd.ru`           |
| IP                 | `185.170.204.91`       | `185.170.204.85`                 |
| Порт               | `21101`                | `19081`                          |
| Заводской номер ФН | —                      | `9999************ / 9999*******` |

## 3. Проверка настроек в «Таблицах» (Тест драйвера FR)

1. Включите ККТ, запустите **«Тест драйвера FR»** последней версии.
2. **«Настройка свойств»** → выберите тип подключения:
   - **«Локально»** (COM-порт) → «Поиск оборудования» → выберите найденную ККТ → «Таблицы».
   - **«TCP сокет»** (USB/RNDIS) → укажите TCP-порт (по умолчанию `7778` или `8240`) → «Проверка связи» → «Таблицы».
3. В разделе **«Таблицы»** проверьте:
   - **Таблица 19 «Параметры ОФД»**: Сервер `ofdp.platformaofd.ru`, Порт `21101`, Таймаут чтения ответа `1000`.
   - **Таблица 15 «Сервер транзакций»**: Режим передачи `1` или `2`; Server ip1–ip4: `185`, `170`, `204`, `91`; Server port `21101`.

## 4. Значения таблиц 15 и 21 по способу подключения

- **COM-порт, интернет через компьютер:** Таблица 15 поле 1 = `1`; Таблица 21 поле 2 = `0`; поле 9 = `0`.
- **USB, интернет через компьютер:** Таблица 15 поле 1 = `1`; Таблица 21 поле 2 = `0`; поле 3 = `1`; поле 4 = `8240`; поле 9 = `1`.
- **COM-порт, интернет через Ethernet:** Таблица 15 поле 1 = `2`; Таблица 21 поле 2 = `1`; поле 9 = `0`. Галочка **«Передавать данные в ОФД»** (Настройка свойств → Доп. параметры → ФН).
- **USB, интернет через Ethernet:** Таблица 15 поле 1 = `2`; Таблица 21 поле 2 = `1`; поле 3 = `1`; поле 4 = `8240`; поле 9 = `1`. Галочка **«Передавать данные в ОФД»**.
- **Wi-Fi:** Таблица 21 поле 5 = `1`; поле 6 = `1`; поле 7 = `id сети wifi`; поле 8 = `пароль wifi`; Таблица 15 поле 1 = `1`.

Расшифровка Таблицы 15: поле 1 — режим передачи (`0` — не передавать, `1` — без шифрования, `2` — с шифрованием). Таблица 21: поле 2 — режим обмена с ОФД (`0` — через драйвер, `1` — через ФР); поле 3 — TCP-сервер (`0` — OFF, `1` — ON); поле 4 — порт TCP-сервера (по умолчанию `8240`); поле 9 — RNDIS (`0` — не включать, `1` — включать).

## 5. Неполадки и их устранение (из статьи)

- **ККТ не реагирует на нажатия кнопок промотки бумаги:** проверить питание, дождаться окончания команды, освободить бумагу; при неисправности — сервисный центр.
- **ККТ не отвечает на команды хоста:** проверить питание, скорость обмена, соединительный кабель; при неисправности — сервисный центр.
- **Нет связи с ОФД:** вероятная причина — **неверные настройки ККТ**; проверить настройки.
- Индикатор ошибки на панели: отсутствие бумаги (красный + звук), авария аппаратной части (двойные вспышки), нарушение целостности ОЗУ / режим 9.

## 6. Граница инструкции

Настройки ККТ должны соответствовать данным, внесённым на сайте ФНС. Для разбора неполадок по конкретной модели Штрих-М статья отсылает к инструкциям производителя (панель «Дополнительные материалы» для соответствующей модели).
