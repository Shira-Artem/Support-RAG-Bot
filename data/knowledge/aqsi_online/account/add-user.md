# aQsi Online: создание пользователя

## Создать пользователя
Для того, чтобы создать Пользователя, который будет пользоваться ЛК aQsi online, необходимо зайти во вкладку “Пользователи” и нажать кнопку “Добавить пользователя” вверху страницы. По нажатии на кнопку “Добавить пользователя”, откроется форма создания нового пользователя. Далее нужно указать почту и имя пользователя, а также присваиваете ему роль ( роль создается заранее во вкладке “Роли”). Затем нажать "СОХРАНИТЬ". При желании можно добавить изображение.

## Ограничения
Это создание новой записи. Для существующей записи есть отдельная карточка редактирования. Источник не устанавливает обязательное название роли администратора и не задаёт матрицу полномочий для задач сотрудника. Уточните необходимые задачи у владельца кабинета.
