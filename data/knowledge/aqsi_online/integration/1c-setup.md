# aQsi Online: интеграция с 1С через драйвер ККТ

## Вопрос клиента
Как подключить aQsi Online к программе 1С?

## Проверенная информация и первичная диагностика
1. Актуальная версия: Aqsi.Integrator-3.9.0.73, скачать: https://aqsi.ru/wp-content/themes/aqsi/files/Aqsi.Integrator-3.9.0.73.msi.
2. Технические требования: Windows Server/Desktop x64 (не ниже 8.1 / 2012 R2); открытые адреса api.aqsi.ru и aqsi.ru, IP 62.76.112.78, порты 443, 8000, 8001; поддержка протокола 3.1 в конфигурации 1С; Visual C++ 2015–2022.
3. Установите .msi, выберите папку, нажмите «Готово» — программа запустится автоматически.
4. В ЛК aQsi: «Настройки» → «Интеграции» → галка «Включить интеграцию» → «Сгенерировать API-ключ» → скопируйте ключ.
5. Вставьте ключ в программу → «Войти» → выберите папку синхронизации → «Сохранить».
6. Настройка в 1С (пример: 1С:Предприятие 8.3, «Розница» ред. 3.0; настройки под учётной записью Администратора)
7. «Настройки» → «Оффлайн оборудование» → «Подключить новое»: тип подключения «Локальное подключение», тип оборудования «ККМ», обработчик «1С: Офлайн-оборудование»; организация и наименование.
8. В «Параметрах подключения»: версия формата обмена 3.1, вид обмена «Файловый», каталог обмена — путь из «Интегратора», файлы ImportData / ExportData.
9. «Правило обмена» → «Создать»: тип «ККМ Офлайн», склад, флажок «Выгружать группы товаров», при необходимости — отбор товаров → «Обновить» → «Сгенерировать SKU» → у всех товаров должна быть цена (если вводится при оплате — 0).
10. «Продажи» → «Обмен с офлайн оборудованием»; «Интегратор» должен быть запущен (значок в панели задач).

## Когда нужен специалист
Настройка защищённых ключей, сертификатов, адреса API и ошибок драйвера — интегратору. Не запрашивать приватные ключи в переписке.

## Применимость
Инструкция описывает интеграцию aQsi с 1С по протоколу ККМ Оффлайн 3.1 через программу «aQsi Интегратор». Поддерживаются все конфигурации 1С с функцией обмена с офлайн-оборудованием, включая облачные версии при работе через тонкий клиент. Названия разделов и версии могут меняться — проверяйте актуальность на дату обращения.
