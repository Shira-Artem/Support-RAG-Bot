# aQsi: ошибка 115 при операциях и закрытии ФН

## Симптомы
ККТ сообщает ошибку 115 при кассовой операции или при закрытии архива фискального накопителя.

## Возможные причины по базе aQsi
- Для кассовых операций — неверно настроенная система налогообложения в профиле кассы.
- При попытке закрыть ФН — наличие неотправленных в ОФД фискальных документов; для закрытия ФН их необходимо передать.
- При работе с маркированным товаром — в карточке товара указан тип маркировки, не соответствующий сканируемому коду Data-Matrix.

## Безопасная проверка
1. Уточнить, при какой операции появляется ошибка, и точный текст сообщения.
2. Если ошибка при кассовой операции: сверить СНО с документами бизнеса. При подтверждённой некорректности исправить через ЛК aQsi: создать профиль настроек касс → выбрать корректную СНО → привязать кассу к профилю → переоткрыть смену → проверить оплату.
3. Если ошибка при закрытии ФН: проверить очередь неотправленных документов и статус связи с ОФД; передать все документы в ОФД до закрытия ФН. Не закрывать ФН до проверки специалистом.
4. Для маркированного товара: сверить тип маркировки в карточке товара со сканируемым кодом Data-Matrix.
5. Не изменять СНО, регистрационные параметры и не закрывать ФН наугад — только после подтверждения специалистом и проверки условий конкретной кассы.

## Эскалация
Изменение СНО, регистрационных параметров или закрытие ФН — только после подтверждения специалистом и проверки условий конкретной кассы.
