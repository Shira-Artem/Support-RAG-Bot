# «Марка не была проверена» при продаже

## Признаки
При переходе к оплате возникает сообщение о непроверенных кодах маркировки. Конкретную причину часто сообщает вторая строка ошибки.

## Что безопасно проверить
1. В текущем чеке найдите проблемную позицию с предупреждающим значком, откройте его описание и запишите точный текст ошибки.
2. Уточните, открыта ли смена; при закрытой смене проверка марки может не выполняться.
3. Если ошибка указывает на неправильное состояние ФН, сравните настройки маркировки и сведения из итогов регистрации ККТ, но не запускайте перерегистрацию самостоятельно.
4. Если не передаются уведомления в ОИСМ, проверьте доступность канала и обратитесь к оператору ОФД, если реквизиты верны.

## Передать инженеру
Перерегистрация, изменение регистрационных признаков, устранение проблем ФН. До проверки причины не советуйте обходить ограничения маркировки.
