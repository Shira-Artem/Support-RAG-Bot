# aQsi: возврат прихода через отложенный заказ

## Вопрос клиента
Как сделать возврат через отложенный заказ aQsi?

## Проверенная информация и первичная диагностика
1. В ЛК aQsi: «Заказы» → «Создать заказ»; при наличии оплаченного заказа его можно использовать как шаблон.
2. Укажите СНО и «Признак расчёта» = «Возврат прихода»; добавьте позиции — наименование должно быть идентично чеку прихода, сумма возврата равна итоговой сумме заказа.
3. Возврат по карте: «Добавить оплату» → тип «безналичный», сумма к возврату, RRN (ЛК → «История чеков» → «Слипы») и сумма транзакции (полная сумма исходного чека прихода) → «Сохранить».
4. Возврат не по карте: тип оплаты указывается в кассе при нажатии «Сделать возврат».
5. Отправьте заказ кнопкой «Отправить на кассу/в магазин/кассиру» — привязка определяет, где он появится (все кассы магазина / конкретная касса / учётная запись кассира).

## Рекомендация (добавленная экспертиза, не из источника)
Не повторяйте возврат и не меняйте тип оплаты, пока не проверен статус исходной банковской операции. Финансовое действие выполняйте только после сверки первичного чека, способа оплаты и согласования с уполномоченным сотрудником.

## Когда передавать специалисту
Финансовое действие выполнять только после сверки первичного чека, способа оплаты и согласования с уполномоченным сотрудником.

## Ограничения
Материал относится к физическим кассам aQsi, а не к облачному сервису aQsi Online. Названия разделов могут отличаться по модели и версии ПО. Не выполнять финансовые, фискальные или регистрационные операции без проверки контекста и полномочий.
