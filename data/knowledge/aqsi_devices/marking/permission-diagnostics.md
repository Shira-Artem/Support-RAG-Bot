# aQsi: почему не проходит проверка кода маркировки

## Вопрос клиента
Честный ЗНАК не отвечает при продаже на aQsi

## Проверенная информация и первичная диагностика
1. Если Честный ЗНАК не отвечает (тайм-аут):
    - Разрешительный режим — это онлайн-проверка кода маркировки в ГИС МТ. Касса отправляет код и ждёт ответ 1,5 секунды (строки 3–5, 41–42).
    - Если за это время ответ не пришёл, чек оформляется без уведомления, а информация о запросе сохраняется в лог-файл (строки 42–43).
    - Чтобы выгрузить лог: подключите кассу к компьютеру через USB → опустите шторку Android → «Зарядка по USB» → «Передача файлов» → перейдите по пути CS10\Внутренний общий накопитель\Android\data\ru.aqsi.cashierworkplace\files\Documents\chestny_znak → перезагрузите кассу перед выгрузкой (строки 43–48).
2. Если проверка не проходит (ошибка):
    - Убедитесь, что касса работает на ФФД 1.2 — на ФФД 1.05 проверка не выполняется (строки 8–10).
    - Проверьте, что токен добавлен в ЛК aQsi (Настройки → Общее → Разрешительный режим) и синхронизация прошла успешно (зелёная галочка) (строки 17–26). Если токена нет — касса выдаст ошибку при продаже маркированного товара (строки 65–66).
    - Сверьте сообщение кассы с перечнем в источнике (строки 50–60): код отклонён фискальным ядром, не найден, не является подлинным, выведен из оборота, заблокирован, не принадлежит организации, истёк срок годности и др.
3. Режим обработки ошибок (настраивается):
    - «Запрещать продажу товара» (по умолчанию);
    - «Пропускать ошибку по соглашению кассира»;
    - «Пропускать ошибку автоматически, кроме случаев, обязательных к уведомлению» (ППР № 1944) (строки 27–34).
4. Важно: разрешительный режим применяется только к чекам прихода; для возвратов и коррекции проверка не выполняется (строки 62–63).

## Когда передавать специалисту
Если ошибка подтверждается через приложение «Честного знака» — свяжитесь с поставщиком и обратитесь в справочный центр системы (строки 60–61). При неоднозначном статусе кода или запрещённом товаре — эскалация в поддержку маркировки.
