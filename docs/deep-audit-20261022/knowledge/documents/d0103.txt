# Как загрузить чеки XML-файлом в АТОЛ Онлайн

## Вопрос пользователя
Как импортировать реестр чеков XML в АТОЛ Онлайн?

## Что проверено по инструкции производителя
В личном кабинете откройте «Загрузка чеков из файлов XML (1.05/1.2)», выберите организацию и магазин, добавьте файл по актуальной XML-схеме и проверьте предварительную проверку формата. После отправки реестра отслеживайте результаты обработки каждого чека и ошибки. Схемы и примеры XML производитель размещает отдельно.

## Важное ограничение / передача специалисту
Никогда не загружайте боевой реестр без проверки на дубли и соответствия выбранному ФФД. Отсутствие ошибки загрузки не гарантирует успешной фискализации всех документов.

> Черновик для тестирования RAG. Перед публикацией сверить с действующим регламентом и профильным специалистом. Область применения — облачные кассы АТОЛ Онлайн, если не указано иное.
