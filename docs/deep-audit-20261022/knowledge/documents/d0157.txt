# Переход облачной кассы АТОЛ Онлайн на ФФД 1.2

## Вопрос пользователя
Как перевести АТОЛ Онлайн с ФФД 1.05 на 1.2?

## Подтверждённые сведения
До перехода проверьте совместимость банка, платёжного агрегатора или собственной интеграции с API v5. После согласования в ЛК АТОЛ Онлайн предусмотрена заявка через «Изменение данных» → «Изменение ФФД». Для маркированного товара дополнительно проверяют соответствующий признак в параметрах магазина и ФНС.

## Важно / когда передать специалисту
Переход затрагивает регистрацию ККТ и может быть необратим без замены ФН. Самостоятельно не запускайте смену без инженера.

> Материал относится к облачному сервису «АТОЛ Онлайн», а не ко всем физическим моделям АТОЛ. Черновик: проверить у профильного специалиста перед публикацией.
