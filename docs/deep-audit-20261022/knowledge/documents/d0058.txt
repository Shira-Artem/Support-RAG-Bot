# aQsi Online: прямое подключение API или CMS

## Вопрос клиента
Как подключить сайт к облачной кассе aQsi через API?

## Что можно объяснить и проверить
Доступны два основных способа: готовый модуль CMS или интеграция по API. Для прямого API сначала получают доступ к тестовой среде через поддержку, проверяют обмен, затем согласуют переход на продуктивный контур с сертификатами и ключами подписи запросов.

## Перед выполнением действий
Не присылайте приватные ключи и секреты в чат. Уточните CMS, рабочий контур, характер ошибки и статус тестовой интеграции.

## Когда нужен специалист
Ошибки подписи, сертификата, доступа к продуктивному контуру — разработчику или специалисту интеграции.

## Применимость
Только облачная касса aQsi Online. Не переносить настройки на физические терминалы aQsi. Проверить актуальность интерфейса и нормативных требований на дату обращения.
