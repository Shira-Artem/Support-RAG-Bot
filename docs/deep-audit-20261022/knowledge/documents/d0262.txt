# Раздел «Кассы» в кабинете партнёра

## Данные для диагностики

В партнёрском кабинете раздел показывает кассы с ошибками регистрации ФНС или блокировкой передачи чеков. Подраздел технической информации может показывать версию прошивки, установленные приложения и канал подключения. По статье эти характеристики доступны только для касс Эвотор с установленным приложением из Evotor Market; для запроса нужны ID приложения и токен.

## Граница доступа

Если нет прав партнёра или данных приложения, этот способ диагностики неприменим. Отдельный подраздел кабинета посвящён архивированию ККТ клиента; его не следует смешивать с архивом касс в обычном кабинете клиента.
