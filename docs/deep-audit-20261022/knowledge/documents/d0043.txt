# aQsi: ошибка ККТ 126 — длина кадра приёма

## Симптом
Ошибка ККТ 126 с сообщением о некорректном значении длины кадра приёма.

## Варианты возникновения в базе aQsi
- При оформлении чека коррекции: проверить согласованность введённых реквизитов. Не формировать новый документ до выяснения причины ошибочных реквизитов.
- При закрытии смены: в статье упоминается обновление ПО устройства как возможный способ устранения.

## Безопасная диагностика
1. Записать точную операцию, код и состояние смены.
2. Проверить модель устройства и текущую версию ПО.
3. При чеке коррекции сверить реквизиты с первичными документами и передать вопрос ответственному специалисту.
4. Обновление ПО выполнять только по официальной процедуре, учитывая резервирование и состояние ККТ.

## Ограничения
Ошибка может иметь разные причины в зависимости от операции. Не исправлять фискальные реквизиты автоматически.
