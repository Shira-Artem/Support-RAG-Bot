# Код ФЛК 508

Этот код касается сравнения общей суммы расчёта в чеке (тег 1020) с суммой стоимостей его позиций с учётом скидок и наценок (тег 1043). Для проверки нужны значения тегов исходного документа по каждой позиции; без них нельзя определить причину расхождения. Оператор указывает, что чек с этим кодом не учитывается ФНС при расчёте выручки. Конкретный способ коррекции должен определить специалист по данным чека и действующим правилам.
