# Как добавить ещё один интернет-магазин к кассе АТОЛ Онлайн

## Вопрос пользователя
Одна облачная касса нужна для двух сайтов. Как добавить второй?

## Что проверено по инструкции производителя
В кабинете АТОЛ Онлайн перейдите «Изменение данных» → выберите компанию → «Параметры магазина» и подготовьте новый список URL. Производитель описывает перечисление адресов через точку с запятой без пробелов; после заявки на изменение данных может потребоваться соответствующая перерегистрация в ФНС. Все сайты должны относиться к одному владельцу ККТ.

## Важное ограничение / передача специалисту
Перерегистрация в ФНС юридически значима; её следует поручать уполномоченному специалисту. Ограничения на перечень URL уточняйте в текущем интерфейсе.

> Черновик для тестирования RAG. Перед публикацией сверить с действующим регламентом и профильным специалистом. Область применения — облачные кассы АТОЛ Онлайн, если не указано иное.
