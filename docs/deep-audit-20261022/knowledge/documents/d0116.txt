# Шаг 5 подключения АТОЛ Онлайн: сведения для регистрации в ФНС

## Вопрос пользователя
Какие данные понадобятся для регистрации облачной ККТ АТОЛ Онлайн в ФНС?

## Что проверено по инструкции производителя
После оплаты пятый шаг личного кабинета содержит регистрационные сведения облачной кассы. Для заявления в ФНС понадобятся данные владельца, модель и заводской номер ККТ, номер ФН, параметры места применения, особенности автоматического устройства, адрес интернет-расчётов и выбранный ОФД. Номера ККТ и ФН берите из кабинета по конкретной кассе, а не из примеров инструкций.

## Важное ограничение / передача специалисту
Регистрация в ФНС — юридически значимое действие. Не подставляйте типовой адрес ЦОД или флажки из чужого примера; всё необходимо сверить по конкретной ККТ и текущему порядку ФНС.

> Черновик для тестирования RAG. Перед публикацией сверить с действующим регламентом и профильным специалистом. Область применения — облачные кассы АТОЛ Онлайн, если не указано иное.
