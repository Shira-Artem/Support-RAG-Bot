# Один УПД поставщика, поступление товара на несколько складов

## Вопрос
Можно ли оформить поступление по одному УПД, если товар физически поступил на разные склады?

## Подтверждённая возможность
Начиная с версии 3.0.188 поддержан сценарий одного документа поступления товаров по единому УПД поставщика и нескольких приходных ордеров М-4 для разных складов.

## Диагностика
1. Уточнить версию 1С и используется ли складской ордерный учёт.
2. Сверить номенклатуру и общее количество по УПД с фактическим поступлением на каждый склад.
3. Проверить, нет ли уже созданных дубликатов поступления по одному первичному документу.
4. Если надо распределить товары по складам, выяснить используемую в организации схему оформления первичных документов.

## Эскалация
Некорректные складские остатки, закрытые периоды или расхождения по маркированным товарам требуют специалиста по учёту/1С.

> **Статус:** черновик. Уточнять применимость к релизу и процессам клиента.
