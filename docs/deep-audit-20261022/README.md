# Support-RAG-Bot: технический аудит, снимок 22.10.2026

Это самостоятельный пакет для анализа в ChatGPT. Источники прочитаны без изменений: обе SQLite открыты через `mode=ro`, активная коллекция Qdrant прочитана через `get_collection/scroll`. LLM, эмбеддинги, индексация и Telegram API при подготовке пакета не вызывались. Время начала и окончания выгрузки — `snapshot.json` (UTC).

## Навигация

- `architecture.md` — тракт ответа от Telegram до сохранения, состояние диалога, hybrid retrieval, промпт, модель и проверка ответа.
- `dialogue-findings.md` — статистика и наблюдения по ручным диалогам; это материал для аудита, без правок работающего бота.
- `knowledge-inventory.md` — состав активной коллекции, метаданные и сопоставление с файлами источников.
- `privacy-and-verification.md` — обезличивание, границы экспорта и результаты проверки.
- `dialogues/free_conversations.json` — все 19 записей свободных разговоров, включая 3 пустые, 134 сообщения и полную сохранённую диагностику ответов.
- `dialogues/feedback_and_escalations.json` — все 20 событий оценки, 3 заявки и 6 событий эскалации. Связь по псевдонимам `conversation_id` и `answer_message_id`.
- `dialogues/dialogue_states.json` — 62 сохранённых состояния после клиентских сообщений и 15 последних снимков состояния.
- `dialogues/expert_sessions.json` — 8 экспертных Telegram-сессий, 264 элемента сценариев, 38 попыток и 31 оценка.
- `dialogues/assistant_reviews.json` — отдельно сохранённые автоматизированные обзоры: 46 попыток; не смешивать их с ручной оценкой пользователя.
- `results/retrieval_by_answer.jsonl` — сохранённая RAG/LLM-диагностика каждого из 67 ответов, включая случаи без retrieval и без оценки.
- `knowledge/manifest.json` — 269 документов: ID, полные метаданные, путь к тексту, точный список chunk ID и контрольные суммы.
- `knowledge/documents/` — 269 текстов документов, нормализованных тем же `DocumentLoader`, который используется при индексации; потенциальные личные реквизиты маскированы.
- `knowledge/chunks.jsonl` — 927 текстов чанков, их порядковые номера и метаданные Qdrant.
- `knowledge/vectors.jsonl` — 927 сохранённых 384-мерных векторов активной коллекции.
- `code/` — снимок исполняемых Python-модулей, файлов зависимостей и Docker Compose. `code/source_hashes.json` содержит SHA-256 исходных файлов.
- `config/public_runtime.json` — действующие параметры без ключей и токенов; `config/package_versions.json` — версии библиотек.
- `prior-tests/` — 20 подготовленных сценариев ручной Telegram-проверки, её отчёт и сравнения retrieval до/после переключения коллекции, а также сохранённые разборы обратной связи и инцидента АТОЛ. Это отдельный исторический набор, не включённый в подсчёт 67 фактических ответов SQLite.
- `summary.json` и `FILE-SHA256.json` — контроль состава и файлов пакета.

Псевдонимы `c####`, `m####`, `s####`, `e####` сохраняют связи внутри архива. Таблица соответствия с Telegram ID, chat ID и исходными UUID не включена. `document_id` и `chunk_id` сохранены как индексные идентификаторы, чтобы диагностику можно было соединить с манифестом Qdrant.

Снимок отражает данные на момент экспорта. Более поздние сообщения или оценки в работающем боте в него не войдут. Векторы и тексты выгружены из активной коллекции `knowledge_sprint_v1_20261022_quality_gate`; исходные тексты всех 269 документов также сверены с её `content_hash` и чанками.
