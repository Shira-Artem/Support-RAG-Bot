# Обезличивание и проверка пакета

Исходные SQLite открывались только с `mode=ro`; Qdrant читалась через `get_collection` и `scroll`. В пакете нет сырых баз SQLite, `.env`, файлов с runtime-токенами, исходных Telegram/chat ID, callback ID и таблицы соответствия псевдонимов. Идентификаторы разговоров, сообщений, экспертных сессий, попыток и API-вызовов заменены стабильными локальными кодами. Диагностика и тексты прошли рекурсивную очистку: токены, ключи, email, IP-адреса, длинные числовые реквизиты, домашние пути Windows, query/fragment URL и служебные поля удалены или маскированы. Агрегированные счётчики замен — `privacy/redaction_counts.json`.

Скрипт сборки сверяет все 269 файлов источников с Qdrant по `content_hash`, текстам и ID чанков; повторное чтение Qdrant с векторами проверяется по одинаковому payload fingerprint. `summary.json` задаёт проверяемые числа строк и статусов. `FILE-SHA256.json` содержит размер и SHA-256 каждого файла архива. После упаковки проверяются список членов, целостность ZIP, эти контрольные суммы, JSON/JSONL, связи документ–чанк–вектор и обезличивание. Отдельные результаты финальной проверки сохраняются в `archive-validation.json` рядом с ZIP.

Автоматическое маскирование не устанавливает истинность текстов и не исключает косвенную идентификацию по уникальной формулировке вопроса. Перед внешней публикацией пакета содержимое следует оценивать с учётом этого ограничения. Для независимого анализа в ChatGPT сохранены диагностические поля всех успешных, неудачных, отказных и неоценённых ответов.

## Результат финальной проверки

Архив открылся без ошибок (`ZipFile.testzip`), перечень вложенных файлов совпал с ожидаемым, размер и SHA-256 каждого файла совпали с `FILE-SHA256.json`. JSON/JSONL разобраны успешно; подтверждены связи 269 документов с 927 уникальными чанками и 927 векторами. Обе исходные SQLite прошли `PRAGMA quick_check` в режиме чтения. В материалах не найдены 32 проверенных исходных идентификатора разговоров/чатов/экспертов и 2 непустых значения секретов из окружения; шаблоны Telegram-токена, API-ключа, Bearer, email и домашнего пути Windows также не найдены. Точное время экспорта, fingerprint Qdrant и подтверждение нулевых LLM/embedding вызовов — в `snapshot.json`.
