# Ручная проверка Telegram — 19.11.2026

Результат интеграционной проверки: новая KB **пока не разрешена для main/runtime** из-за 84 дополнительных падающих тестов, включая grounding и порядок диагностики. Детали: [отчёт](../reports/kb_integration_20261119/report.md). Ручной запуск использует main + существующий Stage3, Hubris `openai/gpt-oss-20b`, `low`, SourceFirst + Coordinator + Semantic Composer. Это проверка известного checkpoint, общий production gate остаётся NO-GO.

**На завершение проверки бот работает на main / прежней Stage3 KB.** Первые два запуска завершились NetworkError; третий после восстановления связи прошёл `getMe` и несколько `getUpdates` подряд с HTTP200. Оставлен один worker, Hubris/low и отдельная SQLite. Реальный входящий вопрос/ответ ещё предстоит проверить владельцу. Сеть была нестабильна; при остановке процесса из корня проекта можно повторить подготовленный обычный запуск:

```powershell
& .\.venv\Scripts\python.exe -X utf8 -u .\.local\kb-integration-20261119\start_bot.py
```

Сейчас `.local/bot.lock` занят оставленным worker — второй экземпляр запускать не нужно. Не обходите lock. Если при будущем запуске появится 409, остановите только новый процесс. `runtime.json` сам по себе не означает успешный polling; в `manual/telegram-http.jsonl` должны появиться успешные `getMe` и `getUpdates`, затем нужен настоящий входящий вопрос и ответ.

В `.env` ничего не менялось. Для процесса используются существующие credentials и список тестировщиков из `EXPERT_TELEGRAM_IDS`; список выбирает SourceFirst, но не закрывает доступ к боту. SQLite, outbox, логи и receipt выделены в `.local/kb-integration-20261119/manual/`. Старые обращения и индексы сохранены. Доставка специалисту отключена: подтверждённая заявка должна сохраниться локально, без обещания уведомить сотрудника.

Если polling удалось запустить, откройте прежнего тестового бота, отправьте `/start`, выберите **Свободный диалог**. Каждый пункт ниже начинайте кнопкой **Новый диалог**, кроме явно указанных продолжений. Не выполняйте технические операции на реальной кассе ради теста.
